## 0. TL;DR（按预登记判读条款）

1. **主结论"CLIP 终值打平"稳定复现**：循环子集 mean Δ(LLM−写死) run 1 = +0.004 → run 2 = **−0.004，符号翻转、幅度都 ≤0.005**。两次合计胜 12 / 负 10 / 平 1，两次都进循环的 6 题里 Δ 同号仅 3——掷硬币水平。按预登记条款，CLIP 终值维度如实判读为**噪声主导，两臂无可辨差异**（run 1 报告本就未宣称方向，此判读与其一致）。
2. **效率优势方向复现，幅度收窄**：LLM 臂循环耗时 run 1 −39% → run 2 −19%（run 1 的幅度含 edit API 时段性变慢，报告当时已标注）；图像调用数 LLM 臂两次均更少（30 vs 36；22 vs 23）。
3. **run 1 的两个次级苗头被 run 2 证伪**：①"LLM 臂达标更多"（5/13 vs 3/13）翻转为 7/10 vs 5/10（写死臂更多）；②"edit_api 选择效应"（LLM 挑时机用 edit 增益更高）完全反转——run 2 写死臂 edit 平均 +0.009（14/23 正向），LLM 臂 edit +0.001。两者均判为噪声。
4. **新量化：管线噪声比臂间效应大一个量级**。同一题、同一管线独立跑两次，基图 CLIP 的 |Δ| 平均 **0.029**（中位 0.019，最大 0.084）——是臂间效应（|0.004|）的约 7 倍。这是"单次运行中任何 ≤0.01 的臂间差都不可判读"的直接证据，也是本次 replication 的最大方法论收获。
5. **稳定复现的行为特征**（两次一致）：改图循环相对基图的增益为正（F +0.015/+0.021，L +0.019/+0.016）；controller 零 fallback、零改诗、零主动 stop、强 rewrite_regen 偏好（77%→86%）；基图直接达标比例高（14/27→17/27），target=0.30 区分度不足在 run 2 更严重；VLM 兑现率臂间差异两次都在测量噪声内。

## 2. 管线噪声的量化（本次新增证据）

同题跨 run 的基图 CLIP raw：|Δ| mean=0.029 · median=0.019 · max=0.084（t26 雪夜 0.357→0.283）。诗生成与图像生成的随机性叠加后，**管线自身波动淹没臂间效应约 7 倍**。推论：
- 实验 B 若只跑一次，无论 Δ 是 +0.004 还是 −0.004 都可能被误读为方向性结论——replication 是必要的而非锦上添花；
- 后续任何想检出 ≤0.01 量级效应的实验，要么固定诗与基图（消掉前半段噪声源），要么把重复次数提到远超本预算的规模。

## 3. mode 级"选择效应"假说：证伪

| 动作单轮增益 | run 1 | run 2 |
| --- | --- | --- |
| 写死臂 edit_api | +0.000（21/36 正向） | +0.009（14/23 正向） |
| LLM 臂 edit_api | +0.013（5/7） | +0.001（2/3） |
| LLM 臂 rewrite_regen | +0.006（12/23） | +0.007（12/19） |

run 1 曾记录"LLM 挑时机用 edit 增益更高"的选择效应苗头（当时已注明 n 小不下结论）；run 2 完全反转。两次合并看：**rewrite_regen 的单轮增益（~+0.006）反而是唯一跨 run 稳定的正值**，edit_api 增益两次方向相反。判读：mode 级差异在本规模下不可辨，run 1 的选择效应观察撤回。

## 4. 唯二跨 run 稳定的单题信号（仅记录）

- **t10 怀古（古城/荒台）**：两次 LLM 臂均大幅胜出（+0.021 / +0.041），且都靠 rewrite_regen 一轮见效——该题基图两次都偏离诗意（0.275/0.277 全场最低档），重画比修补有效，符合直觉。
- **t08 羁旅（客舍/孤灯）**：两次写死臂均大幅胜出（−0.017 / −0.031），edit_api 对该题的夜景光影微调恰好对 CLIP 敏感。

两题合计 4 个数据点，只作现象记录，不构成"哪类题适合哪臂"的结论。

## 5. 结论与叙事口径

**两次独立运行支持的稳定结论**：在 3 轮、CLIP 单指标门控的窄循环里，LLM-driven 控制与写死循环的终值无可辨差异（打平复现）；LLM 臂以略少的调用与更短的耗时达到相当结果（方向复现、幅度不稳）；controller 行为特征（零 fallback、强重画偏好、从不选改诗与主动停）高度稳定。run 1 的两个次级苗头（达标更多、edit 选择效应）被 run 2 证伪并撤回。管线噪声 ≈ 7× 臂间效应的量化结果，解释了为什么 replication 在此类评估中不可省略。

## 6. 限制

1. 仍是 n=27 × 2 次的小规模；"打平"是"未检出差异"，不是"证明无差异"。
2. run 2 的循环子集只有 10 题、与 run 1 重叠 6 题——跨 run 同题配对样本很小。
3. target=0.30 区分度不足未修正（预登记要求条件零改动）；两次运行 27 题中分别有 14/17 题未进循环。
4. 配额已过期，本方向的后续实验（固定基图消噪、target 校准）留待新配额。
