## 0. TL;DR

1. **CLIP 终值上两臂基本打平，方向轻微偏向 LLM 臂但幅度在噪声量级**：全集 mean Δ(LLM−写死)=+0.002；真正进入循环的 13 题里 mean Δ=+0.004（LLM 胜 8 / 负 4 / 平 1），单题 Δ 范围 −0.020 ~ +0.024，与 CLIP 单次评分的抖动同量级。
2. **LLM 臂的确定性优势在效率，不在终值**：循环子集内达标 5/13 vs 写死臂 3/13；平均耗时 263s vs 433s（−39%）；图像 API 调用 30 次 vs 36 次。省时的机制很直白——达标即 stop，而写死臂只会跑满预算。
3. **实验设计教训：target=0.30 对新 gen 模型区分度不足**。14/27 题基图一次生成就 ≥0.30，两臂循环整体被跳过，有效配对样本只剩 13。这也是全集"LLM 更高比例 29.6%"看起来很低的原因——48% 的题是两臂皆零轮的平局。
4. **VLM 硬约束兑现率差异（77.5% / 72.5% / 80.0%）不可判读**：像素完全相同的两张图（t03 基图 vs 写死臂终图）在 temperature=0 下被 qwen-vl-max 判出不同结果，单 kw 级噪声与臂间差异同量级。
5. controller 决策埋点首采干净：30 次决策 0 fallback、0 次选改诗、76.7% 选 rewrite_regen；但 reasoning 文本存在引用上下文数字错误的现象（见 §5）。

## 1. 设置

| 项 | 值 |
| --- | --- |
| 题集 | HARD_CONSTRAINTS 27 独立主题全集（kw v1 冻结），执行顺序预登记写死 |
| 配对方式 | 前半段（诗→prompt→基图→CLIP）只跑一次，`_copy_state` 分叉两臂 |
| 写死臂 | `run_image_improve_loop`，image_improve_mode=edit_api，强度衰减 0.75→0.51 |
| LLM 臂 | 同函数，controller(qwen-plus) 每轮自选 edit_image(rewrite_regen\|edit_api) / refine_poem_and_regen / stop |
| 循环参数 | max_rounds=3 · target raw=0.30 · adaptive_stop(delta≤0.01×2轮) 两臂一致 |
| 图像模型 | gen=qwen-image-2.0-pro-2026-06-22 · edit=qwen-image-edit-max-2026-01-16（QuotaMeter 白名单断言，绕过本地降级兜底） |
| 消耗 | gen 50/100 · edit 43/100 · 完成 27/27 题（题边界截断未触发） |

t01 因记录增强重跑一次；v0 冒烟记录归档于 `eval/runs/llm_loop_ab_v0_smoke/`（非择优替换，见该目录 results.jsonl）。

## 2. 主指标：CLIP raw 终值（配对）

全集（n=27，含 14 题两臂皆未进循环的结构性平局）：

| 臂 | mean | std | median | min | max |
| --- | --- | --- | --- | --- | --- |
| 基图 | 0.299 | 0.028 | 0.300 | 0.244 | 0.357 |
| 写死臂 | 0.306 | 0.021 | 0.305 | 0.265 | 0.357 |
| LLM 臂 | 0.308 | 0.023 | 0.312 | 0.245 | 0.357 |

**循环子集（n=13，基图 <0.30 真正跑了循环的题）**：

| 对比 | 数值 |
| --- | --- |
| LLM − 写死 mean Δ / median Δ | +0.004 / +0.002 |
| 胜 / 负 / 平 | 8 / 4 / 1 |
| 相对基图 mean gain：写死臂 | +0.015 |
| 相对基图 mean gain：LLM 臂 | +0.019 |
| 循环内达标（终值 ≥0.30）：写死臂 | 3/13 |
| 循环内达标：LLM 臂 | 5/13 |

单题 Δ 分布跨 −0.020（t01）到 +0.024（t19），两端都超过均值差一个量级——**单题层面两臂互有胜负，均值差不构成"LLM 更好"的结论**。LLM 臂负得最狠的两题（t01 −0.020、t08 −0.017）都是写死臂 edit_api 恰好有效、而 LLM 反复重画抽不到更好图的题。

按 density 拆：sparse（n=8）mean Δ=+0.008，rich（n=5）mean Δ=−0.002。方向上 LLM 臂在 sparse 题占优，但子样本太小，仅作记录。

## 3. 成本与效率（LLM 臂的实质差异所在）

| 指标（循环子集 n=13） | 写死臂 | LLM 臂 |
| --- | --- | --- |
| 平均 / 中位循环耗时 (s) | 433 / 398 | 263 / 255 |
| 图像 API 调用合计 | 36 edit | 23 gen + 7 edit |
| 平均轮数 | 2.8 | 2.2 |

两个机制：①LLM 臂达标即 stop（5 题在 1-2 轮内达标离场），写死臂达标判断只在轮首、且不达标必跑满；②本时段 edit API 单次 130-175s，比 gen（~60s）慢一倍以上，LLM 臂 77% 的轮次选了 rewrite_regen，天然避开了慢路径。**第②点是时段性的**（edit API 当日显著变慢），不宜泛化。

## 4. mode 级单轮增益（选择效应观察，n 很小）

单轮 delta = 该轮分数 − 上一轮分数（首轮相对基图）：

| 动作 | n | mean delta | 提升轮占比 |
| --- | --- | --- | --- |
| LLM 臂 rewrite_regen | 23 | +0.006 | 12/23 |
| LLM 臂 edit_api | 7 | +0.013 | 5/7 |
| 写死臂 edit_api | 36 | +0.000 | 21/36 |

值得记录的反差：**同一个 edit_api 工具，写死臂无差别每轮用平均零增益，LLM 臂挑时机用则 7 次里 5 次为正**。一个自洽的解释是选择效应——controller 倾向在"构图已对、只差局部"时才选 edit（决策 reasoning 里多次出现此类表述）。但 n=7 太小，且循环"每轮从历史最优图出发"的机制也会影响单轮 delta 口径，此处只作方向性记录，不下结论。

## 5. LLM 决策埋点（诚实性指标首采）

- 30 次决策：JSON 全部解析成功，**fallback 0（0.0%）**，stale_override 2（自适应停止覆盖 LLM 决策）。
- 工具分布：edit_image(rewrite_regen) 23 / edit_image(edit_api) 7 / **refine_poem_and_regen 0 / 主动 stop 0**。改诗工具一次未被选用——对"给了工具就会被用"的假设是个反例；主动 stop 为零意味着"省预算"完全靠达标判断而非 LLM 自觉。
- 决策质量瑕疵（v0 冒烟与正式跑均观察到）：reasoning 文本会错引上下文数字，如上一轮刚从 0.290 掉到 0.262，reasoning 却写"delta 为正"。不影响本实验指标（动作合法、埋点如实），但说明 controller 的数值 grounding 不可靠，是后续 prompt 改进点。

## 6. VLM 硬约束兑现率：差异不可判读

| 图 | hit/total | 兑现率 |
| --- | --- | --- |
| 基图 | 31/40 | 77.5% |
| 写死臂终图 | 29/40 | 72.5% |
| LLM 臂终图 | 32/40 | 80.0% |

臂间差异全部来自 3 题的单 kw 翻转：t03 写死臂 −1、t24 写死臂 −1、t18 LLM 臂 +1。其中 **t03 的基图与写死臂终图像素完全相同（该题 0 轮，MD5 一致），qwen-vl-max 在 temperature=0 下仍给出 2/2 与 1/2 两种判定**——即测量噪声本身 ≥ 臂间差异。结论：本实验规模下 VLM 兑现率无法区分两臂，仅 t24（图确实被 edit 改动后掉词）提示"改图可能破坏已兑现的硬约束"值得后续单独设计实验。

## 7. 限制

1. n=27 全集、单次运行（single-shot），所有数字不代表重复运行的稳定值；CLIP 单次评分自身抖动与观测到的臂间差同量级。
2. target=0.30 区分度不足，有效配对样本 13——**下次同类实验应先用基图分布校准 target**（如取基图 median 上方 0.02-0.03）。
3. CLIP_MAX_RETRIES=0 为实验条件（生产默认 2），生产环境的循环收益会略高于此处观测。
4. 两臂固定先写死后 LLM 顺序执行，edit/gen API 延迟的时段波动会不对称地进入耗时对比（§3 已标注）。
5. controller 用 qwen-plus；换更强决策模型的结果未测，本报告不外推。

## 8. 结论怎么用（作品集叙事）

诚实的一句话版本：**在这个窄循环（3 轮、单指标门控）里，LLM-driven 控制没有带来 CLIP 终值上的可辨优势，但以更少调用、更短耗时达到了相当的结果，效率差异由"达标即停 + 避开慢路径"两个可解释机制构成；决策埋点全程零 fallback，工程链路可信。** 这与 6/27 的 n=5 先导实验（LLM 臂均值更低且更贵，当时受本地降级污染）相比，方向由负转平，主要差异来源是本次配额隔离与同基图配对消掉了两个混杂因子。
