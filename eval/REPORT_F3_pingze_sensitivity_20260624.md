## 1. F3 命题与方法

**F3 命题：** LLM-as-judge 对格律（pingze）权重接近 0，主要看 intent / imagery / cohesion / aesthetics。

**为什么关心：** 它决定评委能不能替代规则打分器。若评委压根不在乎格律，擂台选出的「最好的诗」可能出律，规则 scorer 就必须作为硬约束保留。

**方法：** retrospective 切片主跑 `matchups_per_input`（双向 pairwise + 评委一致票多数决），不重跑 API。对每个 (local_base, local_lora) matchup，按三种方式分析。

**报告第 67 行（原版）预先定义了判据**：三块一致才算强证据；不一致 = 评委对 pingze 的态度因评委/情境而异。这是原版最好的部分 —— 见 §6。

> **样本量：** 3 胜 1 平 0 负，剔除平局后 p = 0.5³ = **0.125**，不显著。87.5% 这个数的分母是 4、分子步长 0.5，**只能取 9 个离散值之一，最小刻度 12.5pp** —— 一局翻转就跳 25pp，报到小数点后一位没有信息量。
>
> **更根本的是判据本身。** base 赢有两种解释，此设计无法区分：
> - **(A)** 评委不看格律 → 意境赢了
> - **(B)** 评委看格律，但意境优势足够大，压过了格律劣势

> 上表 4 个 pair 的意境差是 +0.094 / +0.178 / +0.073 / +0.136，**均值 +0.120**。原版把这描述成「意境维度**持平/略胜**」，与数据不符 —— 这是**大幅领先**。
>
> 要区分 A/B，需要的是**剂量-反应关系**：base 需要多大的意境优势才能翻盘。意境只领先 0.01 就能赢 → 格律权重确实近 0；要领先 0.15 才能赢 → 格律权重不低。**n=4 分不了层。**

## 3. 对照：改按意境差分桶（但它一半是同义反复）

同一批 83 局，把自变量从 pingze 差换成**意境差**（4 judge 维度均值之差）：

| 桶 | n | local_lora 胜率 | 桶内 pingze 差均值 |
|---|---|---|---|
| base 意境大优 ≥ 0.10 | 21 | **12.5%** | +0.268 |
| base 略优 0 ~ 0.10 | 26 | **34.0%** | +0.269 |
| 持平 = 0 | 3 | **66.7%** | +0.208 |
| lora 略优 −0.10 ~ 0 | 28 | **75.0%** | +0.219 |
| lora 大优 ≤ −0.10 | 5 | **90.0%** | +0.300 |

**完美单调，跨度 77.5pp**，且各桶 pingze 差几乎一致（+0.21 ~ +0.30）—— pingze 被自然控制住了。

### 3.1 这张表一半是同义反复 —— 必须写明，否则它会变成下一个被误读的东西

- **同义反复的一半：** 意境差是 4 位评委打的分，pairwise 胜负也是**同一批评委**判的。评委的判断与评委自己的打分一致，**不构成独立证据**，只是一次自洽性检验。
- **有信息量的一半：** pingze 是**规则算的、与评委无关**，而它预测不了胜负。

### 3.2 排除一个看似合理的替代解释

pingze 差与意境差的相关性：**Pearson r = +0.079，Spearman ρ = +0.075**（n=83）—— **两者近似独立**。

所以问题**不是**「两个变量共变、互相污染」（这个假设被数据否掉了），而是**原分析选错了自变量**：胜负几乎完全由评委自己的维度打分决定，与规则算的格律分无关。

## 4. 原理性障碍与后果

**障碍：** 要把 §3 那半句有信息量的相关性变成**因果**结论，需要的对照是「**同一首诗，只改平仄、不动意境**」。这在诗里做不到 —— 改平仄必然改字，改字必然改意境。

**后果一：** `build_f3_controlled.py` 的扩样实验按当前分析口径不必跑。**n 从 4 到 64 跨不过这道坎**，省下 1–2 小时 API。

**后果二（可迁移）：** 这个障碍对**任何在生成式作品上做单变量控制实验**的尝试都成立。生成式输出的各维度由同一次采样联合决定，无法像实验科学那样固定其余因子。这是本报告最有价值的产出。

## 5. 哪个工程决定不依赖 F3

**「生产必须保留 rule-based 格律硬约束」这条成立，且不依赖 F3。**

无论评委对格律的权重是 0 还是 0.3，都不能把格律保证交给评委 —— 理由是规则可验证、可复现，而评委判断与规则分的关系既未被证明、也（见 §4）无法被证明。`README.md` 对应表述方向正确，本次仅把它的引用依据从「F3 结论」改为「格律硬约束的理由」本身。

### 7.3 范围比初判要小 —— 两处需要澄清

- **`eval_refine.py` 没有判定分支**，只输出表格。`REPORT_eval_refine` 里那句「唯一显著正向维度」是**人写的**，与上述两个脚本**不同源**。
- **`analyze_clip_dual.py:199`「数据不足，无法判定」不是样本量闸门** —— 触发条件是 `best_rho is None`（算不出 ρ），与 n 无关。

### 7.4 若要加样本量闸门，min_n 应当这样定

不拍脑袋，从「要区分判据的 0.40 和 0.25 这两档需要多大样本」倒推。单样本比例检验，H₀: p=0.25，H₁: p=0.40，α=0.05 单侧（判据是「≥40%」），power=0.80：

```
n = [1.645×√0.1875 + 0.8416×√0.24]² / 0.15²
  = [0.7123 + 0.4123]² / 0.0225
  = 1.2647 / 0.0225
  ≈ 56.2   →   min_n = 57
```

**本报告分析 2 的 n=4，是所需量的 7%。**

闸门若要加，必须放在阈值判定**之前** —— n 不足时无论 `a_rate` 多少都只输出「样本量不足，不判定」，而不是在「强支持」后面加括号说明。
